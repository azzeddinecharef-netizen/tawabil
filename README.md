# صفحة هبوط الدورة

تطبيق عربي متوافق مع الهاتف للتعريف بدورة وجمع طلبات التسجيل وإدارتها. يتطلب Node.js 24 أو أحدث ولا يحتاج إلى تثبيت حزم إضافية.

## التشغيل المحلي

عيّن كلمة مرور خاصة قبل تشغيل الخادم؛ لا توجد كلمة مرور افتراضية في الشيفرة:

```powershell
$env:ADMIN_PASSWORD = 'ضع-كلمة-مرور-خاصة-هنا'
npm start
```

ثم افتح `http://localhost:4173` لصفحة الدورة أو `http://localhost:4173/admin` للإدارة.

تُخزّن الطلبات والإعدادات في قاعدة SQLite داخل `storage/course.sqlite`. احفظ نسخة احتياطية من مجلد التخزين.

تتيح لوحة الإدارة البحث في الطلبات وتحديثها، وتعديل عنوان الدورة ووصفها وروابط الفيديو والصوت. يقبل الفيديو روابط YouTube وVimeo أو رابط HTTPS مباشر، والصوت رابط HTTPS مباشر. لم تُرفق مواد فعلية، لذلك تظهر مساحات توضيحية حتى إضافة الروابط.

## الاختبار والنشر

شغّل `npm test` لاختبار التسجيل والدخول والاستمرارية والتحقق من البيانات والإعدادات. يستخدم الاختبار كلمة مرور مؤقتة معزولة.

للنشر على Railway، أضف `ADMIN_PASSWORD` من صفحة Variables، واضبط `DATA_DIR=/data` مع قرص دائم مركّب على `/data`. يستخدم التطبيق HTTPS إذا ضُبط `COOKIE_SECURE=1`. يمكن ضبط المنفذ عبر `PORT`. اختر كلمة مرور قوية قبل استقبال بيانات حقيقية؛ يجمع النموذج معلومات شخصية مثل الهاتف وتاريخ الميلاد.
